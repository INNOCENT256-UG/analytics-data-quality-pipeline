# Project 1: Business Analytics Pipeline

## Overview

This project demonstrates how to transform raw business data into reliable, analysis-ready datasets using Python, pandas, SQL, and data quality testing.

## Objectives

* Inspect and understand raw business data.
* Clean missing, duplicated, and inconsistent records.
* Transform data into a suitable analytical structure.
* Calculate business performance metrics using SQL.
* Implement data quality checks.
* Track code changes using Git.
* Document the pipeline and its results.

## Technology Stack

* Python
* pandas
* SQL
* pytest
* Git and GitHub

Additional technologies will be introduced as the project develops.

## Project Structure

* `data/raw/`: Original datasets.
* `data/processed/`: Cleaned and transformed datasets.
* `src/`: Python source code.
* `tests/`: Automated tests.
* `sql/`: SQL queries and transformations.
* `docs/`: Supporting documentation.
